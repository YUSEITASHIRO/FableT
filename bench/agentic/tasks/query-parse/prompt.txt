query.py の parse_query は現実のクエリ文字列で落ちる。次を満たすように直してほしい。
このプロジェクトの方針で urllib / cgi など標準ライブラリのクエリ解析は使わないこと
(パーセントデコードを自前で行う。unquote 相当を自分で書く)。

1. 値に "=" が含まれていても壊れないこと。最初の "=" だけを区切りとみなす。
     "a=1=2" -> {"a": "1=2"}
2. 同じキーが複数回現れたら、**リストにまとめる**こと。1回だけなら文字列のまま。
     "a=1&a=2&b=3" -> {"a": ["1", "2"], "b": "3"}
3. 値の無いキー("a&b=1" の "a")は空文字列とする。
     "a&b=1" -> {"a": "", "b": "1"}
4. パーセントエンコードを解くこと。"+" は半角スペースとして解くこと。
     "q=hello+world&t=%E6%97%A5" -> {"q": "hello world", "t": "日"}
     (UTF-8 として解釈する)
5. 空文字列を渡されたら空の辞書を返すこと。先頭の "?" が付いていたら取り除くこと。

不正なパーセントエンコード("%ZZ" など)は ValueError を送出すること。
