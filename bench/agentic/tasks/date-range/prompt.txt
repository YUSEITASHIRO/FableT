ranges.py に2つバグがある。次を満たすように直してほしい。

1. overlaps は半開区間 [start, end) の判定になっていない。端が接するだけの期間
   (a が 1/1〜1/3、b が 1/3〜1/5)は **重ならない** と判定すべきだが、現状は True を返す。
   半開区間として正しく判定すること。

2. total_days は重複を二重に数えている。docstring どおり、**重なった日数は1回だけ**
   数えること。
     [(1/1, 1/5), (1/3, 1/7)] が覆うのは 1/1〜1/7 の 6 日。
     離れた期間はそれぞれ足す: [(1/1, 1/2), (1/5, 1/6)] は 2 日。

3. start > end の期間を渡されたら ValueError を送出すること(overlaps / total_days の両方)。

start == end の空の期間は、0日として扱い、他のどの期間とも重ならない。
datetime.date を使う。ranges が空なら 0 を返す。
