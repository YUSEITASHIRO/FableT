wrap.py の wrap は壊れている(先頭に空白が入る、width を超える、最後の行が落ちる)。
仕様どおりに実装し直してほしい。このプロジェクトの方針で標準ライブラリの textwrap は使わないこと。

1. 各行の長さは width 以内に収めること。単語の途中では折り返さない。
2. 単語同士は半角スペース1つで連結する。**行の先頭・末尾に空白を残さないこと。**
3. 最後の行も落とさずに返すこと。
     wrap("a bb ccc", 5) -> ["a bb", "ccc"]
     wrap("aaa bbb", 3)  -> ["aaa", "bbb"]
4. width より長い単語は、その単語だけで1行にする(途中で切らない。width を超えてよい)。
     wrap("ab abcdefgh ij", 4) -> ["ab", "abcdefgh", "ij"]
5. 空文字列や空白のみの入力は空リストを返す。連続する空白は1つの区切りとして扱う。
6. width が 1 未満なら ValueError を送出すること。
