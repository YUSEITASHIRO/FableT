slug.py に問題がある。次を満たすように直してほしい。

slugify:
1. 英数字とハイフン以外の記号を取り除くこと(現状は "Hello, World!" が "hello,-world!" になる)。
     slugify("Hello, World!") -> "hello-world"
2. 前後のハイフンを取り除き、連続するハイフンは1つにまとめること。
     slugify("  --Hello--  World  ") -> "hello-world"
3. 記号しか含まないタイトルなど、結果が空文字列になる場合は ValueError を送出すること。

unique_slug:
4. **衝突が2回以上あっても正しく回避すること。** 現状は "-2" を付けるだけなので、
   その "-2" 自体が既存にあると衝突したままになる。
   衝突する限り "-2", "-3", "-4"... と番号を増やして、空いている最初のものを返すこと。
     unique_slug("hi", {"hi"}) -> "hi-2"
     unique_slug("hi", {"hi", "hi-2"}) -> "hi-3"
     unique_slug("hi", set()) -> "hi"
5. existing は変更しないこと(呼び出し側の集合を書き換えない)。

日本語などの非 ASCII 文字の扱いは変えなくてよい(取り除いてよい)。
