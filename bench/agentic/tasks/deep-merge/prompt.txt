config.py の merge には3つ問題がある。次を満たすように直してほしい。

1. **引数を破壊しないこと。** 現状は base をそのまま書き換えて返しているため、
   呼び出し側が持っている既定値の辞書が汚染される。新しい辞書を返すこと
   (ネストした辞書も、呼び出し後に結果を書き換えて base に影響が出ないこと)。
2. **ネストした辞書は再帰的にマージすること。** 現状は上書きしてしまうため、
   ネストしたキーが消える。
     merge({"db": {"host": "h", "port": 1}}, {"db": {"port": 2}})
       -> {"db": {"host": "h", "port": 2}}
3. **override の値が None のキーは「削除」を意味する。** 結果からそのキーを取り除くこと。
   base に無いキーを None で指定された場合は、単に何もしない(エラーにしない)。
     merge({"a": 1, "b": 2}, {"b": None}) -> {"a": 1}

型が食い違う場合(片方が辞書、もう片方が辞書でない)は override 側の値で上書きする。
