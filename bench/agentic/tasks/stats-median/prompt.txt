stats.py に3つ問題がある。statistics / numpy などのライブラリは使わず、自前で直すこと。

1. **引数を破壊している。** values.sort() が呼び出し側のリストを並べ替えてしまう。
   入力を書き換えずに計算すること。
2. **median が偶数個のときに正しくない。** 要素数が偶数なら**中央2つの平均**を返すこと。
     median([1, 2, 3, 4]) -> 2.5
     median([3, 1, 2]) -> 2
3. **percentile が線形補間していない。** docstring どおり、
   k = (n-1) * p/100 の小数部を使って前後の値を線形補間すること。
     percentile([1, 2, 3, 4], 50) -> 2.5
     percentile([1, 2, 3, 4], 0)  -> 1
     percentile([1, 2, 3, 4], 100) -> 4
     percentile([10, 20], 25) -> 12.5

4. 空リストを渡されたら ValueError を送出すること(両方の関数)。
   percentile の p が 0〜100 の範囲外なら ValueError を送出すること。
