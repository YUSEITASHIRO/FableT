diffs.py の diff は行番号を突き合わせているだけで、docstring が言う「最長共通部分列」に
なっていない。そのため1行挿入しただけで、以降の全行が削除+追加として出てしまう。

最長共通部分列(LCS)に基づく差分に直してほしい。標準ライブラリの difflib は使わないこと
(このプロジェクトの方針。LCS を自前で実装する)。

満たすべきこと:

1. 共通する行はできるだけ "=" として残すこと。
     diff("a\nb\nc", "a\nX\nb\nc") は
       [("=", "a"), ("+", "X"), ("=", "b"), ("=", "c")]
     となること(現状は b と c まで -/+ になってしまう)。
2. 削除は "-"、追加は "+" で表し、**同じ位置では削除を先に、追加を後に**並べること。
3. old を空にすると全行が "+"、new を空にすると全行が "-" になること。
4. 完全に同じテキストなら、すべて "=" になること。
5. 復元可能であること: "=" と "-" を集めると old の行に、"=" と "+" を集めると new の行になる。

行末の改行は splitlines で落として構わない(既存どおり)。
